# Contributing / المساهمة

Contributions are welcome. Keep changes focused and never commit secrets or private data.

1. Fork and create a focused branch.
2. For prompt files, use lowercase safe slugs and include `name`, `title`, `description`, `template`, `tags`, and `version`.
3. Run `prompt-library validate`.
4. Run `pytest -q` for code changes.
5. Update tests and both README language sections when behavior changes.

Pull requests should explain the problem, behavior change, and validation performed.

المساهمات مرحب بها. اجعل التغييرات محددة، ولا تضف مفاتيح أو بيانات خاصة. تحقّق من ملفات القوالب باستخدام `prompt-library validate` وشغّل الاختبارات عند تعديل الكود، وحدّث التوثيق الإنجليزي والعربي عند تغيير السلوك.
